## synchronous system model
In distributed systems, a synchronous system model is a model where we assume that the system has known upper bounds on time for all important operations. In other words, we assume that the system behaves predictably with respect to time.

This is one of the fundamental models used to reason about distributed algorithms.

**The three main system models**

Distributed systems are usually described using three timing models:

1. Synchronous model → time bounds are known
2. Asynchronous model → no timing assumptions
3. Partially synchronous model → some timing assumptions hold, but not always
